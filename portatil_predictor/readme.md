# Predictor de compra de clientes

Modelo de Machine Learning que predice si un cliente comprará,
según su edad y los minutos que pasa en la web.

## Contenido
- `modelo_clientes.pkl` — modelo entrenado (LogisticRegression)
- `usar_modelo.py` — script de ejemplo que carga el modelo y predice

## Qué datos espera
Dos números por cliente:
1. Edad (años)
2. Minutos en la web

## Cómo ejecutarlo

pip install scikit-learn joblib
python usar_modelo.py
